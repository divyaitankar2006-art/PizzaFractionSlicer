# Pizza Fraction Adventure

## Description
Pizza Fraction Adventure is a fun, child-friendly educational game designed to teach children fractions through interactive pizza slicing and shading. Players can cut pizzas into equal pieces, shade specific fractions, and solve fraction-based multiple-choice and word problems. The game features 12 progressively challenging levels to guide children from basic concepts to fraction mastery.

## Features
- **12 Educational Levels:** Ranging from simple slicing to equivalent fractions and word problems.
- **Interactive Radial Slicing:** A fully custom geometry engine that allows children to accurately cut the pizza from the center to the edge.
- **Level-Specific UI:** A clean interface that dynamically displays only the controls required for the current challenge, reducing visual clutter and confusion.
- **Fun Animations & Sound:** Kid-friendly mascot guidance, sound effects, and confetti celebrations for positive reinforcement.

## Technologies Used
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla, Canvas API)
- Vite (Development Server & Bundler)
